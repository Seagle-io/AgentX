    La vostra password principale resta con voi

    Argon2id la trasforma in una chiave sul vostro dispositivo: 256 MiB di memoria per tentativo, per rendere rovinosi gli attacchi con schede grafiche.

  2. 02

    Crittografia locale

    Ogni dato viene sigillato con XChaCha20-Poly1305 (libsodium), con un nonce casuale di 192 bit a ogni salvataggio.

  3. 03

    Il server vede solo rumore

    Viene sincronizzata solo la cassaforte cifrata. La chiave di accesso è separata: non permette né di risalire alla vostra password né di decifrare alcunché.
